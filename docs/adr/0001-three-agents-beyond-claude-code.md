# devflow supports Codex, Cursor and OpenCode beyond Claude Code

devflow 1.2.0 was built with installers for Codex, Cursor, OpenCode, Gemini CLI and Pi. Before tagging it, Gemini CLI and Pi were removed completely, uninstall included, to focus on testing three agents well in real sessions. None of the five had been run in a real session, and 1.2.0 was never released with Gemini or Pi, so no installs needed carrying over. The Gemini and Pi adapters remain in git history (PR #36) if they come back.
