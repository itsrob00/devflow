# Patterns to cut

## Content

- **Empty -ing phrases.** "highlighting", "ensuring", "showcasing". Delete, or say the real thing.
- **Vague attribution.** "Experts believe", "it is widely known". Name the source or delete.
- **Generic conclusions.** "The future looks bright." State a specific fact or plan.

## Language

- **Stock vocabulary.** Additionally, crucial, delve, enhance, foster, intricate, landscape, pivotal, showcase, tapestry, testament, underscore, vibrant. Use plain words.
- **Fancy ways to say "is".** "serves as", "stands as", "boasts". Say "is" or "has".
- **"Not just X, but Y."** State the point.
- **Forced groups of three.** Use the number the content has.
- **Synonym cycling.** Pick one word for a thing and repeat it.
- **False ranges.** "from X to Y" where X and Y aren't on one scale. List the items.
- **The fancier synonym.** "utilize" and "leverage" are "use". "numerous" is "many". "in the event that" is "if".
- **Abstract metaphor nouns.** Substrate, vector, nexus, bedrock, paradigm, "surface" as in "API surface". Name the thing.

## Style

- **Long dashes.** Don't use them. End the sentence or use a comma.
- **A colon as a connector** in the middle of a sentence. A colon before a list or an example is fine.
- **Bold on everything.** Bold a lead-in that names an item, not every noun.
- **A bold label that restates its own line.** "**Performance:** Performance improved". Write it as prose.
- **Title Case Headings.** Use sentence case.
- **Decorative emoji** in headings and bullets.
- **Curly quotes.** Use straight ones.

## Chat leftovers

- **Chatbot phrases.** "I hope this helps", "Let me know if", "Certainly".
- **Flattery.** "Great question". Answer directly.

## Filler

- **Filler phrases.** "In order to" is "to". "Due to the fact that" is "because". "It is important to note that" is nothing.
- **Stacked hedges.** "could potentially possibly" is "may".
- **Adverbs propping up a weak verb.** "significantly improves" becomes the measured change.

## Plain speech

- **Say what it does, not how it feels.** "The database stays close at hand" names a feeling. Name the mechanism or the number.
- **Dense sentences.** If the reader has to backtrack, split it. One idea per sentence.
- **Passive voice** that hides the actor. "Queries are validated" becomes "the compiler validates queries".
- **Flourish.** Aphorisms, rhetorical fragments, personified code. Use the literal phrase.
- **Over-compression.** Dropped articles, arrows and symbols in place of sentences, private abbreviations. "Parser rejects bad date, exit 2, no write" becomes "The parser rejects a bad date, exits with code 2 and writes nothing."
